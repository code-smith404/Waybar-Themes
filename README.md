# Waybar Themes

Waybar configurations for Linux desktops. Choose a release from the repository
root with the interactive installer:

```sh
git clone https://github.com/code-smith404/Waybar-Themes.git
cd Waybar-Themes
./install.sh
```

## Releases

- **[V2.0](V2.0/README.md)** — Arch Linux + MangoWM theme based on the supplied
  reference: four workspaces, a translucent rounded navy bar, and compact
  system status. Its centered active-window group shows the real focused title
  and the corresponding installed application icon.
- **[V1.1](V1.1/README.md)** — earlier charcoal theme with hardware-brightness
  controls and five workspaces.

Use `./install.sh --dry-run` to review either install without changing the
system. Or install a release directly with `./V2.0/install.sh` or
`./V1.1/install.sh`.
